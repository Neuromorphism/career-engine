# Contextual work progression titles

Work menus across all 261 paths now use action titles that describe the advancing work. Recurring training subjects move from their initial task to a concrete method drawn from the authored description, a recorded trial, failure-case checks, and (where present) adaptation, documentation, and review. Original choices that already described distinct work retain their wording; original choices using phase prefixes are revised too.

Career alternatives distinguish a reviewed case, coordinating a team, and building lasting capacity. The data remains fully expanded in `data/careers.toml`, with the browser artifact regenerated by the existing compiler. There is no runtime title generator.

The medicine vaccination sequence uses the reviewed copy: prepare for a conversation; plan how to address questions and concerns; practice explaining benefits and risks; verify accuracy and understanding; adapt to the patient's needs.

Supporting copy retains the specialty context without repeated generic phase instructions. The shared UI puts that extra context in an optional “Task context” disclosure and omits it when the title already contains the entire description. Projects continue to show their brief and deliverable. The training introduction makes the fictional-case or controlled-exercise setting explicit.

Choice IDs, legacy titles and outcomes, saved completion snapshots, task subjects, models, rewards, rates, and prerequisites are unchanged. Completed work continues to display the wording recorded when it was completed.

Validation covers all professions and specialties for retired title prefixes and repeated titles within recurring subjects, plus the exact vaccination sequence. The compiler rejects retired prefixes and repeated training titles. The existing gameplay, history compatibility, world, and model checks also apply.


## Scenario-specific revision (v0.10.1)

The previous revision still used generic “record a trial” and “find failure cases” wrappers. This revision replaces 2,168 training titles with individually written scenario actions across all 261 paths. Concrete stages cover choosing a method, running a trial or supervised teaching exercise, checking a specific result, and (for longer tracks) responding to a named change, documenting the case, and reviewing lessons. First choices with generic field-level labels also receive concrete scenarios; first choices already describing distinct work retain their titles.

Examples: the community-hall route progresses through an exit sketch, a step-free walkthrough, a blocked-stair capacity check, and rerouting after an exit closes. The batch-reaction case compares cooling and relief options, simulates cooling failure, and checks relief against runaway heat release.

Training choices include explicit `title_aliases` for their retired labels. History refreshes only a saved title matching an alias on the exact selected choice. It does not rewrite stored saves, change choice IDs, or relabel genuinely different legacy tasks. Entries without saved title snapshots still use their legacy task title. This replaces the earlier blanket policy of displaying every saved title verbatim.

Module and HTML query versions advance to v0.10.1 so returning browsers fetch the revised copy and history formatter. Save keys and gameplay values remain unchanged. Compiler and tests reject the retired wrappers, cover all paths, and verify the two reported sequences and safe history-label refresh.
