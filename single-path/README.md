# Single-path endpoint

Open `/single-path/` from the Career Engine home screen. This is the original career playthrough: choose a field, complete prerequisite-based training and work samples, select an action at each career milestone, and reach 10,000 mastery at occupation depth.

`app.js` starts the shared `../src/app.js` interface in single mode. Career definitions and curricula are shared with world and AI endpoints. The original browser save keys are retained, so moving the UI from the root into this subproject preserves progress on the same site origin.
