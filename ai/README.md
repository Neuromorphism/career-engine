# AI competition endpoint

Open `/ai/` from the Career Engine home screen. This is a single career playthrough with a task-sensitive AI rival competing to reach mastery first.

`app.js` starts the shared `../src/app.js` interface in AI mode. Career definitions, curricula, actions, and impact scenarios match the single-path and world endpoints. AI progress retains its separate browser save key and is not merged into the persistent world. Rival rates remain game balance parameters, not labor-market forecasts.
